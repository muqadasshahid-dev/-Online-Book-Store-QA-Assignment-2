# 📚 Online Book Store Testing

## Project Overview

This repository contains my **Software Quality Assurance (SQA) Manual Testing Assignment** for the **Online Book Store** application. The objective of this project was to apply manual testing techniques by creating a comprehensive test plan, designing functional test cases, organizing them into test suites, executing test runs, and generating execution reports using **TestWorthy**.

This project demonstrates my understanding of the Software Testing Life Cycle (STLC), test case design, test execution, and defect reporting.

---

## Project Objectives

- Create a High-Level Test Plan
- Design and document manual test cases
- Organize test cases into logical test suites
- Execute test cases using TestWorthy
- Record execution results (Pass, Fail, Blocked, Skipped)
- Generate Test Execution Reports
- Export test cases and execution reports
